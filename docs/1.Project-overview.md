This project demonstrates a practical web application security assessment conducted against Damn Vulnerable Web Application (DVWA), an intentionally vulnerable web application designed for security training and testing.
I will use Burp Suite Community Edition to intercept, inspect, modify and analyze HTTP requests and responses.
The main objective is to understand common web application vulnerabilities, evaluate their potential security impact, document evidence and recommend appropriate measures.
testing is performed in an authorized DVWA training environment.
